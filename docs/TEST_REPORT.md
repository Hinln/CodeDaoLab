## 5. 沙箱专项验证要点

- 玩家代码在 `python -I -E -u -X utf8` 子进程中真实执行；
- 语法错误 → 返回中文友好摘要与错误行号；
- 运行错误（如除零）→ 返回异常类型与 traceback 片段；
- 无限循环 → 5 秒超时强杀并给出“心魔入体”提示；
- 内存超限 → Job Object 内存上限（256 MB）+ 轮询监控，返回“灵力耗尽”；
- 危险模块（os/import 等）与危险内建被屏蔽，`open` 类函数仅允许标准库目录白名单；
- 玩家输出无法伪造验证结果（随机 marker 解析）。

## 6. 未覆盖/已知限制

- 沙箱为进程级隔离，面对**对抗性**逃逸（如类继承链内省）无法完全根除；教学场景可接受，文档已明示；
- 未做跨平台自动化（Windows 为主目标，POSIX 路径已实现但未在 CI 中验证）；
- E2E 依赖本机 Chrome 与 Node，仅用于开发回归。
