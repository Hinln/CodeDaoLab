# 《码上飞升》V0.2.5 产品审查报告

> 审查时间：2026-08-08（V0.2.5 夜间优化任务·第一阶段）。
> 审查方式：通读 CODEX / PRODUCT / GAME_DESIGN / PYTHON_CURRICULUM / TECH_ARCHITECTURE 与 V0.2 全部文档；
> 并用 Playwright 驱动 Chrome 实机走查新玩家建角、任务、秘境、突破、藏经阁、成就、首页续玩全流程。

## 1. 当前优势

- **完整教学闭环**：凡人 → 炼气一~十层 → 筑基天劫 → 筑基 → 金丹流程完整可玩；玩家代码真实执行、验证无关键词匹配。
- **数据驱动架构**：课程/任务/NPC/功法/道具/秘境/成就全部 JSON 驱动，扩展新内容成本低。
- **沙箱安全成熟**：子进程隔离（`python -I`）、超时、内存上限、文件白名单与防穿越、随机 marker 防伪造。
- **AI 师尊守则**：L1→L4 分级引导，坚持「引导 > 提示 > 解释 > 答案」，不替玩家代答。
- **测试体系完善**：pytest 224 项 + E2E 31 项 + 发行构建冒烟 9/9（本阶段前基线）。

## 2. 最大体验问题（走查实测）

- **新手世界观导入薄弱**：建角后直接进入洞府地图，第一分钟缺少「代码即法术」的世界观交代与下一步指引，玩家容易迷茫。
- **地图卡片首屏溢出**：1280×800 视口下地图卡片延伸到折叠线以下，藏经阁/机缘簿等入口需滚动才能发现。
- **藏经阁超长滚动**：13 项功法教学全文默认展开，页面高度约 1415px，翻找目标功法体验差。
- **成长反馈平淡**：任务完成、修为入账、属性变化缺少视觉反馈；突破弹窗仅一行文字，缺少「新境感悟/新功法」的获得感。
- **弹窗互相遮挡**：成就弹窗与突破弹窗叠放时遮挡「继续」按钮，实测需先手动关闭成就弹窗。

## 3. 优化方向（本次已落地）

- **新手体验**：新增「入道启程」弹窗（世界观 + 青玄子引导 + 下一步指引），关闭后洞府修行按钮脉冲高亮引导。
- **成长反馈**：任务通过后追加「✦ 奖励入账」行；修为/悟性/心境/Debug 经验变化金色闪烁；突破弹窗新增新境界感悟与新参悟功法。
- **UI 体验**：地图卡片紧凑化（首屏全部可见）；藏经阁功法讲解默认折叠、点击展开。
- **稳定性**：新增存档健壮性 / API 边界 / 心境钳制 / 秘境边界 / 沙箱补充测试共 15 项。

## 4. 未纳入本次范围（未来版本）

- 地图系统 / 联机系统 / 商业系统（任务明确禁止，属未来版本）。
- 跨平台打包、CI 自动化、账号与云存档（V0.3 计划）。
