> 版本：v0.2.5（产品打磨）。时间：2026-08-08。

## 1. 优化内容

### 第一阶段 · 项目审查

- 通读全部项目文档并实机走查全流程，产出 `docs/NIGHT_REVIEW.md`。

### 第二阶段 · 新手体验

- **入道启程弹窗**（`#modal-intro`）：建角后首次进入弹出，交代「代码即法术」世界观与《Python 真解》设定，青玄子传音给出下一步指引（前往洞府修行参悟 `print()`）。
- **防重复**：`localStorage("ca_intro_seen")` 记录，仅首次建角展示。
- **下一步引导**：关闭弹窗后洞府修行按钮脉冲高亮（`pulse-cta`），明确当前目标。

### 第三阶段 · 成长反馈

- **奖励入账行**：任务提交通过后，在结果区追加「✦ 奖励入账：修为+X …」。
- **属性变化动效**：修为/悟性/心境/Debug 经验变化时金色闪烁（`flash-gold`）。
- **突破详情**：突破弹窗新增「新境感悟 + 新参悟功法」详情行（`#bt-detail`，功法名显示 `t.title`）。

### 第四阶段 · UI 体验

- **地图卡片紧凑化**：内边距/间距/图标尺寸压缩，1280×800 实测全部入口卡片首屏可见（折叠线以下仅剩 NPC 带）。
- **藏经阁折叠**：功法讲解默认收起，点击「展开讲解」再展示，解决 1415px 超长滚动。

### 第五阶段 · 稳定性测试

- 新增 `tests/test_v02_5_stability.py` **15 项**：损坏存档返回 None、槽位路径穿越清洗、V0.1 version=1 存档自动迁移、V0.2 字段存档往返；空代码/无 body 提交不 500、未知道具 400、未知任务 404；连续失败心境钳制 0、成功后修复与 streak 恢复、attempts 只增不减；秘境超境界 403、未知秘境运行 400；沙箱空代码与相对路径穿越拦截。

### 第六阶段 · 代码质量

- 清理 `static/js/app.js` 中 `realmName()` 死代码。
- 检查 `game/` 全部模块无未使用导入；`node --check` 前端语法通过。

## 3. 测试结果

- **pytest**：`python -m pytest -q` → **239 passed, 32 skipped**（基线 224 + 新增 15，0 failed）。
- **E2E**：`node scripts/e2e_test.js` → **31 项全部通过**（含入道弹窗关闭步骤，弹窗不遮挡后续点击）。
- **发行构建**：`python scripts/build.py` → 冒烟 **9/9 PASS**，产物 `dist/码上飞升-v0.2.5.pyz`。

## 4. 已知问题

- `POST /api/secret-realms/<id>/run` 对未知秘境返回 400「请先进入秘境」而非 404（与 submit 的 404 不一致，行为可接受，已用测试固化）。
- `flashAttrChanges` 依赖地图状态 DOM 结构（`#map-cultivation` 为 `<b>`、其余为 `span`），已由 CSS 选择器覆盖；若前端状态区结构大改需同步。
- 入道弹窗由 `localStorage` 记忆，清除浏览器数据后再次建角会重新展示（符合预期）。
- 发行包要求目标机器安装 Python 3.10+ 与 Flask（沿用 V0.2 约束）。
