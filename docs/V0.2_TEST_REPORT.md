## 5. 性能与安全检查

- **性能**：沙箱 5 秒超时强杀无限循环；内存上限（Job Object / setrlimit）；秘境生成器沙箱自检重试上限 8 次。
- **安全**：玩家代码在 `python -I` 隔离子进程真实执行；危险模块/内建屏蔽；洞府内文件读写白名单 + 路径穿越拦截；`seed_files` 服务端预置文件防穿越；存档槽位名白名单。
- **存档**：多槽位 JSON，V0.1（version 1）自动迁移；秘境解锁/通关次数/成就/道具等新字段全部持久化。

## 6. 已知问题与限制（非阻断）

- 本地 AI 师尊为规则引擎（离线可用）；外部大模型需自行配置 `CA_AI_BASE_URL` / `CA_AI_API_KEY` / `CA_AI_MODEL`。
- 秘境挑战一次进入保留一份；重新进入会生成全新挑战（符合随机玩法设计）。
- 无账号/云存档系统，存档保存在本机用户数据目录。
- 代码天宫（化神）与万象幻境（金丹~元婴）目前只能通过 API/对话解锁验证，完整 UI 流程已由青云秘境覆盖，后续版本可增加可视化引导。
- V0.1 已知限制（如仅本地运行、无多人在线）继续保留。
