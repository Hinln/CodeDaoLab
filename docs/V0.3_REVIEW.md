# 《码上飞升》V0.3 体验审查报告

> 审查时间：2026-08-08（V0.3 产品设计阶段·第一阶段）。
> 审查方式：实机体验当前 V0.2.5 版本完整新玩家流程（Playwright 驱动 Chrome，1280×900），
> 逐屏记录文案与交互；截图存档于 `.tools/v03_shots/`。
> 核心问题：玩家会觉得「我是在修炼代码」，还是「我是在做 Python 练习」？

## 1. 当前玩家流程（实测）

1. **标题屏**：「☯ 码上飞升 / 大道三千，代码亦可入道」→ 开始修行 / 继续修行。
2. **建角**：输入道号、选灵根（金木水火土）、存档槽位 → 创建。
3. **入道启程弹窗**：交代「代码即法术」世界观与《Python 真解》，青玄子传音指引（参悟 `print()` 唤醒灵牌）→ 前往洞府修行。
4. **洞府地图**：一张「功能卡片面板」——洞府修行 / 炼丹房 / 渡劫台 / 藏经阁 / 机缘簿 / 秘境入口 / 储物袋 / 成就碑 + 底部 5 位 NPC 横带。
5. **任务页**：剧情文案 + 教学块（灵气初识 / print 真言 / 心法口诀）+ CodeMirror 编辑器 + 运行/提交。
6. **通过 → 突破**：成就弹窗 → 突破弹窗（新境感悟 + 新功法）→ 返回地图。
7. **自由活动**：藏经阁翻阅功法（讲解折叠）、NPC 对话（节点树）、秘境面板、成就碑、储物袋。

## 2. 世界观表现（优点）

- **隐喻体系完整且统一**：代码=法术、变量=灵力容器、Bug=心魔、Debug=破境、突破=境界提升；教学块用「真言/心法口诀/灵气」包装，不破坏学习准确性。
- **仪式感已建立**：入道弹窗、突破详情（新境感悟+新功法）、奖励入账行、属性金色闪烁——关键节点都有「事件感」。
- **任务剧情有世界味**：实测任务「唤醒灵牌」（让灵牌显示『天地玄黄，宇宙洪荒。』）把 `print` 练习包装成世界事件；「第一道真言」借守门石狮之口要求 `Hello, World!`，包装自然。
- **AI 师尊守则**：L1→L4 分级引导，坚持「引导 > 提示 > 解释 > 答案」，不替玩家代答。

## 3. 沉浸感不足（核心结论）

实机体验后，玩家目前**更接近「在做 Python 练习，只是界面是修仙风」**，而非「生活在修仙世界」。差距集中在四层：

### 3.1 空间层：世界没有「地方」，只有「菜单」

- 洞府/炼丹房/藏经阁/渡劫台/秘境入口在地图上只是**一排功能卡片**，彼此没有位置关系、距离感、可达性。
- 玩家无法「走出洞府、穿过山门、进入青云城」——不存在移动与探索行为。
- 结果：地图更像「功能导航」，而非「可生活的世界」。

### 3.2 人物层：NPC 不在「场」，只是「按钮」

- 5 位 NPC 是地图底部一条横带上的图标；点开是对话框，关掉即消失。
- NPC 没有位置（不在对应地点）、没有状态（忙/离开/等待）、没有关系（好感度/熟识度）、没有自己的故事线推进。
- 青玄子是「师尊」却永远站在同一个地方说同一句话——人物是静态资源，不是世界居民。

### 3.3 事件层：世界不会「发生事」

- 主线线性推进：当前任务 → 突破 → 下一任务，玩家没有「世界在发生什么」的感知。
- 没有时间流逝、没有宗门动态（宗门被袭/丹药失窃/秘境异动）、没有随机事件（奇遇/危机）。
- 奇遇（机缘簿）目前只是「支线任务列表」，并非真实遭遇。

### 3.4 选择层：玩家没有「自己的路」

- 主线唯一路径；支线/秘境是旁路但没有反馈到世界（通关后只有计数+奖励）。
- 没有自由目标：玩家永远被「当前任务」牵引，缺少「我想去探索 X / 我想修炼 Y 功法」的内在动机。

## 4. 最大不足排序（按对沉浸感的影响）

1. **缺少空间探索**（地图是菜单不是世界）——影响最大。
2. **NPC 静态化**（无位置/状态/关系）——世界没有居民感。
3. **世界无事件**（无动态剧情/随机事件/时间感）——世界没有「活着」的感觉。
4. **玩家无自由目标**（线性任务牵引）——缺乏长期留存动机。
5. **教学与叙事的「套皮感」**：部分任务故事短平快，教学块仍明显是教科书段落，世界观包装深度不一。

## 5. 优化方向（V0.3 设计输入）

- **空间**：引入二维「区域-地点」地图（青云宗/青云城/后山秘境），地点有位置、连接、解锁条件；现有功能卡片升级为地图上的地点入口。
- **人物**：NPC 绑定地点、好感度、在场状态与专属故事线。
- **事件**：主线章节制 + 随机奇遇 + 境界剧情；世界状态随进度变化。
- **选择**：多线目标（主线/支线/功法修炼/探索），所有成长仍以真实代码验证为门槛（禁止挂机）。
- **技术**：数据驱动新增 `world` / `story` / 功法独立数据；最大化复用现有 NPC/对话/任务/存档架构（详见 `docs/V0.3_DESIGN.md`）。
