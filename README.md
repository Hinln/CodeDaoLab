# CodeDaoLab | 码上飞升

> 大道三千，代码亦可入道。

《码上飞升：青云宗篇》是一款把真实 Python 编程变成修仙施法的 2.5D RPG。你将创建自己的修士，探索青云宗，与 NPC 对话、修习功法，并通过亲手修改和运行 Python 代码击败 Bug 妖。

当前 Godot 版本：**v0.2.1 新手引导增强版**

## 这是一款怎样的游戏？

- 代码就是法术：变量、循环和字符串等 Python 知识会成为修行功法。
- Bug 就是心魔：观察运行结果、诊断错误、修改代码，最后发动攻击。
- 结果真实执行：试炼不是选择题，答案会交给隔离的 Python 环境运行和验证。
- 对初学者友好：任务灵光、方向距离、分步提示和青玄子诊断会陪你完成第一章。

完全没有编程经验也可以开始。遇到问题时，先运行代码观察结果，再跟随界面中的诊断逐步修改即可。

## 下载后如何启动

### Windows 发布包

1. 准备 Windows 10 或 Windows 11，并安装 Python 3.10 或更高版本。
2. 下载 `CodeDaoLab-Qingyun-Demo-v0.2.1.zip`，完整解压到一个普通文件夹。
3. 双击 `Start-Qingyun-Demo.bat` 启动游戏。
4. 不要直接在 ZIP 压缩包内运行，也不要单独移动 `.exe` 或 `.pck` 文件。

发布包已经包含 Godot 运行时，不需要另外安装 Godot。Python 用于真实执行游戏中的代码试炼。

## 基本操作

| 操作 | 按键或按钮 |
| --- | --- |
| 移动 | `W` `A` `S` `D` 或方向键 |
| 与人物、地点、敌人交互 | 靠近目标后按 `E` |
| 查看当前目标 | 右上角任务卡 |
| 重看新手教程 | 顶部“指引”按钮 |
| 保存进度 | 顶部“存档”按钮 |
| 查看已学内容 | 顶部“功法”按钮 |
| 快速运行代码 | `Ctrl + Enter` |
| 快速提交验证 | `Ctrl + Shift + Enter` |

如果按键没有反应，先用鼠标点击一次游戏窗口，再尝试移动或交互。

## 第一次游玩路线

### 1. 创建角色

开始新游戏后，依次选择：

- 道号：你在青云宗中的名字。
- 灵根：金、木、水、火、土五种灵根会改变施法主色和部分评价。
- 身份：决定角色的背景描述与部分剧情表达。

确认后进入青云宗。第一次进入世界时会自动出现四步修行指引。

### 2. 学会移动与交互

使用 `WASD` 或方向键移动。跟随地面的发光路径前往左上方的**弟子洞府**，靠近青玄子后按 `E` 交谈。

迷路时查看右上角任务卡：

- 它会显示目标地点。
- 它会提示目标相对方向和距离。
- 抵达目标范围后会显示“按 E 交互”。

### 3. 完成代码试炼

进入试炼后，不要急着直接提交。推荐始终按下面的顺序操作：

1. 阅读题目要求和“目标回响”。
2. 查看或修改左侧 Python 代码。
3. 点击“1 · 运转观阵”，真实运行一次代码。
4. 对照右侧的“天地回响”和自动诊断。
5. 修改代码，再次运行，直到实际输出与目标完全一致。
6. 点击“2 · 天地验证”正式提交并完成试炼。

“运转观阵”只负责运行和观察，不会直接完成任务；即使输出已经正确，也必须再点击“天地验证”。

判定会严格比较以下内容：

- 文字是否一致。
- 数字和顺序是否一致。
- 空格与换行是否一致。
- 中文、英文标点是否一致。

例如目标末尾包含中文句号 `。`，代码输出中也必须保留这个句号。

### 4. 前往演武场

完成弟子洞府的基础试炼后，关闭试炼窗口，继续跟随任务灵光前往地图中央的**演武场**。靠近地点后按 `E`，继续完成变量与循环相关修行。

### 5. 挑战后山 Bug 妖

完成基础功法后，前往地图右下方的**后山入口**。Boss 战共有三式，每一式都遵循同一套破招流程：

1. 运行代码，观察报错或输出。
2. 阅读青玄子的自动诊断。
3. 找出语法、运行过程或结果中的问题。
4. 修改后再次运行确认。
5. 结果正确后发动攻击。

不要只凭代码外观判断答案。Boss 战要求你用真实运行结果证明修改正确。

### 6. 完成第一章

破除三层心魔后返回青云宗，完成引气入体并查看章节结算。之后仍可继续游历、拜访地点、查看功法，或保存当前进度。

## 看懂试炼反馈

| 界面反馈 | 含义 | 下一步 |
| --- | --- | --- |
| 语法断裂 | Python 无法理解当前写法 | 检查括号、引号、冒号和缩进 |
| 灵力反冲 | 代码开始运行后发生异常 | 查看最后一行报错，检查变量名、类型和运算 |
| 超时冻结 | 程序运行时间过长 | 检查循环是否能结束、计数是否变化 |
| 法术显化但落点不符 | 代码能运行，但输出不符合目标 | 逐字符比较文字、顺序、空格、换行和标点 |
| 实际与目标一致 | 本次运行结果正确 | 点击“天地验证”正式提交 |
| 天地验证通过 | 试炼已经完成 | 收功返回并继续任务 |

试炼窗口中的“求师尊指点”会逐级提供方向、提示、解释和答案。“诊断代码”则会根据最近一次真实运行结果说明问题类型。

## 常见问题

### 人物为什么不能移动？

先关闭遮挡地图的对话、试炼或功法窗口，再点击游戏画面。使用 `WASD` 或方向键移动。

### 靠近 NPC 后没有反应？

继续靠近，直到界面出现“按 E”提示，然后按 `E`。任务卡显示“已抵达目标区域”时通常已经进入交互范围。

### 输出已经正确，为什么任务还没完成？

“运转观阵”只是预运行。确认实际回响与目标一致后，还需要点击“2 · 天地验证”。

### 循环题为什么没有任何输出？

`pass` 只表示跳过，不会显示内容。需要在循环内部加入正确缩进的 `print(...)`。

### 明明看起来一样，为什么仍然不通过？

重点检查行尾标点、空格和换行。右侧差异诊断会分别展示目标与实际结果，按提示逐项核对。

### 双击启动脚本后提示找不到 Python？

安装 Python 3.10 或更高版本，并在安装时勾选 **Add Python to PATH**。安装完成后重新打开游戏。也可以通过环境变量 `CODEDAO_PYTHON` 指定 Python 解释器路径。

### 界面显示不完整怎么办？

建议使用不低于 `1280 x 720` 的桌面分辨率，并将游戏窗口最大化。内容较长的区域可以使用鼠标滚轮或右侧滚动条查看，底部操作按钮会保持在窗口内。

### 存档会保存我输入的代码吗？

不会。存档会保留角色、任务、功法与挑战经历，但不会保存你在编辑器中输入的源码。离开试炼前如需保留代码，请自行记录。

## 从源码运行 Godot 版

开发环境要求：

- Godot 4.7.1
- Python 3.10 或更高版本
- Windows PowerShell，用于项目脚本

当前 Godot 版本位于 `feature/godot-edition` 分支：

```powershell
git clone --branch feature/godot-edition https://github.com/Hinln/CodeDaoLab.git
cd CodeDaoLab
godot --path godot
```

也可以用 Godot 编辑器直接打开 `godot/project.godot`，然后运行项目。若系统中存在多个 Python，可设置：

```powershell
$env:CODEDAO_PYTHON = "C:\Path\To\python.exe"
godot --path godot
```

## 开发者命令

运行 Godot 自动检查：

```powershell
godot\scripts\run_tests.ps1
```

构建 Windows 发布包：

```powershell
godot\scripts\build_release.ps1
```

发布产物会生成在 `godot/dist/`，该目录不会提交到 Git 仓库。

### 当前版本适合体验什么

- 从零理解“阅读目标、运行观察、诊断差异、修改代码、提交验证”的编程闭环。
- 学习 Python 的字符串输出、变量运算和基础循环。
- 体验编程知识与修仙剧情、地图探索、NPC 对话和 Boss 战的结合方式。
- 为课程难度、新手提示、界面布局和后续内容方向提供反馈。

## 后期重点开发方向

以下方向按当前优先级排列。具体内容会根据试玩反馈调整，不代表固定发布日期。

### P0：稳定性与新手体验

- 继续覆盖不同分辨率、系统缩放和超长提示文本，保证关键按钮始终可见。
- 完善键盘操作、焦点状态、退出确认、异常恢复和存档安全。
- 优化首次启动、Python 环境检测和错误提示，降低安装与运行门槛。
- 增加更清晰的阶段目标、失败复盘和卡关救援，让零基础玩家始终知道下一步。

### P1：Python 课程与挑战扩展

- 从变量和循环继续扩展到条件分支、函数、字符串、列表、字典和异常处理。
- 加入模块、文件读写与面向对象编程等中后期课程。
- 建立由易到难的题目梯度、知识复习、错题回顾和掌握度评估。
- 增加可重复挑战与参数变化，避免只记住固定答案。

### P1：RPG 内容与成长深度

- 开发新的宗门区域、主线章节、支线任务、随机奇遇和可探索地点。
- 扩充 NPC 阵容、关系事件与身份分支，让选择影响对话和修行路线。
- 完善境界突破、功法搭配、修为资源和长期成长目标。
- 让编程知识真正影响探索、解谜和战斗，而不只是独立的答题窗口。

### P1：战斗与 Bug 妖系统

- 增加语法、类型、边界条件、状态变化和算法思路驱动的 Bug 妖。
- 丰富 Boss 阶段机制、战斗反馈、功法联动与失败后的针对性教学。
- 加入更多“先预测、再运行、后解释”的挑战，强化调试思维。

### P2：正式美术与声音

- 将程序化占位表现逐步替换为统一的东方水墨修仙场景、角色和特效资源。
- 增加角色动作、表情、战斗演出、天气变化与更明确的交互反馈。
- 完善环境音、界面音效、施法反馈和分区域音乐主题。

### P2：发布与社区建设

- 完善版本更新说明、可下载 Release、崩溃信息收集和玩家反馈入口。
- 评估 Linux 与 macOS 构建，并持续验证不同 Python 环境的兼容性。
- 补充贡献指南、内容制作规范和适合社区参与的课程与关卡数据格式。
