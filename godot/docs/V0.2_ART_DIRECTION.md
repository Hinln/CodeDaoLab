# CodeDaoLab Godot Edition V0.2 美术与声音规范

## 视觉语言

- 基底使用墨青、松绿、石灰，金色只用于目标、功法完成和突破。
- 世界图形保持几何水墨剪影，人物与 UI 使用相同低饱和材质感。
- 红色仅用于 Bug 妖、反噬与危险，不用于普通按钮装饰。
- 动态效果以缓慢呼吸、流云和灵息漂浮为主，避免持续高频闪烁。

## 地点识别

- 山门：石阶、宗门旗、风声与远钟。
- 弟子居：竹影、灯火、木鱼与木廊回响。
- 藏经阁：叠檐、金色尘埃、书页与低沉室内声。
- 演武场：阵纹脉冲、破风与远处喝声。
- 后山：山石、雾带、溪流与低频妖风。

## 声音原则

- 程序化环境音只提供空间底色，不压过对话和代码反馈。
- 正确施法、失败反噬和突破使用不同频段，玩家无需只靠颜色判断结果。
- “减少动态效果”启用后，视觉脉冲降低，但关键声音和文字反馈保留。
