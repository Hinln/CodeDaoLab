# 《码上飞升：青云宗篇》美术资源生产规范

## 1. 视觉方向

- 核心风格：东方修仙、水墨幻想、2.5D RPG。
- 关键词：青山云海、古建筑、石阶、松木、青玉灵光、宣纸留白、克制金线。
- 主色：深墨青 `#071B20`、松石绿 `#316B61`、云灰 `#DCE4DD`、旧纸金 `#D6B86A`。
- 危险色：心魔暗红 `#C74B36`，仅用于错误、战斗和失败反馈。
- 禁止：紫色主导、霓虹赛博、写实照片、像素与厚涂混搭、现代物件、无法统一的随机素材。

## 2. 视角与比例

- 地图统一使用三分之二俯视的 2.5D 视角，建筑垂直线保持一致。
- 玩家与 NPC 的世界实体高度基准 56 像素，头身比例约 1:3.5。
- 建筑入口至少比角色宽 2.5 倍，确保交互点清晰。
- Boss 可占 180 至 260 像素视觉直径，但不得遮挡代码编辑区。

## 3. 分阶段资源策略

- 原型期：Godot 原生图形和程序化剪影，验证尺寸、碰撞、层级和交互。
- Alpha：替换标题主视觉与关键章节背景，保留可玩实体占位。
- Beta：按同一模板批量生产玩家、三名 NPC、五处地点和 Bug 妖动作帧。
- Release：统一色彩、描边、阴影、透明边缘和导入设置，再补 UI 图标与环境特效。

## 4. 资产要求

### 地图

- 16:9 主视觉需保留左侧或下方 UI 留白。
- 实际碰撞与寻路不能依赖绘制细节，背景图只承担氛围。
- 五处地点必须从轮廓上可区分：山门、洞府、藏经阁、演武场、后山入口。

### NPC

- 青玄子：松石青、白发、克制金饰，沉静授业者。
- 玄机长老：旧纸金、藏书纹样，严谨古板。
- 云游子：灰蓝、罗盘或行囊，洒脱神秘。
- 同批素材必须锁定同一镜头、光向、头身比和描边宽度。

### UI

- 面板为半透明墨青，边框采用 1 至 2 像素青玉或旧金。
- 教学文本必须高对比、可长时间阅读；叙事装饰不可压过代码编辑器。
- 成功使用青玉绿，错误使用心魔红，奖励使用克制金色。

### Bug 妖

- 轮廓表现“代码结构失序”，而非普通野兽。
- 三阶段分别体现语法断裂、逻辑回流、真名错乱。
- 禁止恐怖血腥，保持教学产品可接受的幻想威胁感。

## 5. AI 生成与验收

- 每种资产先生成 1 张风格母版，通过后再扩展变体。
- 提示词必须包含用途、视角、构图、光线、调色、材质、禁止项和无水印要求。
- 生成后检查：风格一致性、透视、肢体、透明边缘、文字伪影、分辨率和版权风险。
- 未通过检查的资源不得进入运行场景；项目必须始终能退回程序化占位资产。
